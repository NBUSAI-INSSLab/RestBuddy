# 今日小憩（RestBuddy）

面向 Windows 10 的桌面效率工具：把「定时休息、任务日历、当日提醒、开机自启」放进一个应用，帮助保持健康的工作节律。基于 PySide6 开发。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 今日总览 | 实时时钟、今日任务醒目列表、快速添加、完成率统计、下次休息倒计时 |
| 任务日历 | 月历视图标记有任务的日期，按天增删改任务（优先级 / 类别 / 时间 / 提前提醒） |
| 定时休息 | 自定义工作间隔与休息时长，到点全屏播放音乐休息，支持推迟、跳过、严格模式、生效时段 |
| 软件配置 | 五套配色方案、全屏休息界面（图片轮播/警示）、开机自启、启动状态、数据导出与备份 |

## 运行

```bat
run.bat
```

或手动：

```bat
python main.py
```

依赖：`pip install -r requirements.txt`（仅 PySide6）。

## 启动行为

- **开机自启动**：软件配置页勾选后写入当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，可用任务管理器取消。
- **启动界面状态**：
  - *默认状态*：每次启动进入「默认起始页面」中选择的页面；
  - *上一次打开状态*：恢复上次离开时的页面与窗口大小位置。
- **关闭窗口**：默认最小化到系统托盘继续计时（可在软件配置中更改），托盘菜单可「显示主窗口 / 立即休息 / 退出」。

## 配色方案

内置五套完整配色，入口有两处：标题栏的 🎨 调色盘按钮（下拉即切）与「软件配置 → 外观与配色」（含色卡预览）：

| 方案 | 特点 |
| --- | --- |
| 薄荷绿 · 浅色 | 默认方案，清爽浅底 + 薄荷绿主色 |
| 薄荷绿 · 深色 | 深底护眼，薄荷绿高亮 |
| 橙色 · 暖阳 | 暖白底 + 深橙主色，整体暖色调 |
| 橙蓝 · 活力 | 深蓝侧边栏 + 橙色主按钮 + 蓝色点缀，对比鲜明 |
| 黑灰 · 极简 | 炭黑底 + 银灰主色，主按钮为浅底深字 |

- 每套方案的文字颜色（正文、次要文字、按钮文字、侧边栏文字）均按 WCAG 对比度单独配置，正文与按钮文字对比度 ≥ 4.5:1，不会出现看不清的情况。
- 消息弹窗、任务编辑对话框、今日提醒卡片、全屏休息层、右键菜单、工具提示均跟随当前配色。
- 配置保存在 `config.json` 的 `theme` 字段（`light / dark / orange / orangeblue / gray`）。

## 定时休息

- 设定工作间隔（默认 45 分钟）与休息时长（默认 5 分钟），仅在「生效时段」内计时。
- 到点后：默认弹窗询问（立即休息 / 推迟几分钟 / 跳过本次）；勾选「到点后自动进入全屏休息」则直接铺满屏幕。
- 全屏休息界面：环形倒计时 + 呼吸引导圆 + 休息小贴士 + 背景音乐（支持循环 / 随机 / 音量 / 静音）。
- 严格模式下不可跳过、不可提前结束，适合强制护眼。

## 全屏休息界面

新版休息全屏页采用「左轮播 + 右倒计时」双卡片布局：

- **图片轮播**：在「软件配置 → 全屏休息界面」指定的目录（默认 `%APPDATA%\RestBuddy\slides`）
  放入 jpg / png / bmp / webp 等图片即可自动轮播，带 Ken Burns 缓慢推拉与交叉淡入淡出，
  底部显示图注与指示点；点击轮播区域或按空格键可手动切换一张。
- **内置放松内容卡**：目录里没有图片时，自动改为轮播 6 张放松内容卡
  （20-20-20 护眼法则、4-2-6 深呼吸、颈肩舒展、补水提醒、视线远近调节、放松节律）。
- **结束前警示跳动**：剩余时间进入警示秒数（默认 15 秒，可设 5–120 秒）后，
  倒计时环变为警示色并持续上下跳动，屏幕四周出现呼吸式光边，
  底部弹出「即将结束 · 还剩 N 秒，准备回到工作」的醒目警示条。
- 快捷键：`空格 / →` 切换轮播，`M` 静音，`Esc` 结束休息（严格模式下无效）。

## 数据与文件

- 任务数据：`%APPDATA%\RestBuddy\tasks.db`（SQLite）
- 配置文件：`%APPDATA%\RestBuddy\config.json`
- 轮播图片目录：`%APPDATA%\RestBuddy\slides`（可在软件配置中更换）
- 运行异常日志：`%APPDATA%\RestBuddy\error.log`
- 软件配置页支持导出任务 CSV、备份配置 JSON。

## 目录结构

```
RestBuddy/
├── main.py                    # 程序入口（单实例保护 + 异常日志）
├── run.bat                    # Windows 一键启动
├── requirements.txt
└── app/
    ├── config.py              # 配置管理
    ├── database.py            # 任务 SQLite 数据层
    ├── autostart.py           # 开机自启动（注册表）
    ├── theme.py               # 五套配色方案与全局样式表
    ├── icons.py               # 内置矢量图标
    ├── main_window.py         # 主窗口（无边框 + 侧边导航 + 托盘）
    ├── services/
    │   ├── break_service.py   # 休息节奏状态机
    │   └── music_player.py    # 休息音乐播放
    ├── views/                 # 四个功能页面
    │   ├── dashboard.py       # 今日总览
    │   ├── calendar_view.py   # 任务日历
    │   ├── break_view.py      # 定时休息
    │   └── settings_view.py   # 软件配置
    └── widgets/               # 任务卡片、对话框、全屏休息层（轮播+警示）、当日提醒等
```
